如何获取 SESSDATA？
  1. 在电脑浏览器打开 bilibili.com 并登录你的账号。
  2. 按键盘 F12 打开开发者工具，切换到 应用 (Application) 标签。
  3. 在左侧展开 Cookie，找到 SESSDATA，复制其值并粘贴在上方。
  4. 凭据仅保存在本机客户端，仅用于请求 B 站官方字幕 API。

关于 vidnote v0.3.4

vidnote 是一款专为知识提炼与归档设计的 B 站视频笔记工具。 本版本采用 Tauri 2.0 编译原生 Rust 桌面端与后台托盘核心，大幅优化内存占用与渲染流畅度。

  • 原生托盘核心：关闭窗口自动最小化至系统托盘，右键托盘图标可一键呼出或快速抓取剪贴板。
  • 原生文件对话框：输出目录选择与打开文件直接调用 Windows 系统原生 API。
  • 智能关键帧抽帧：无需下载庞大视频，自动从 storyboard 抽取高画质时间轴缩略图并内嵌至文档。
